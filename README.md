# ActiPoints
A web-based system that integrates seamlessly with college databases to track, verify and manage student activity points. The platform replaces manual and error-prone tracking methods with an automated, transparent, and real-time system for both students and faculty.


## 🚀 Features

* Activity submission with proof upload
* Automated point calculation based on KTU guidelines
* Role-based access (Student / Faculty / Admin)
* Real-time progress tracking
* Dashboard for monitoring performance

## 🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Django (Python)
* Database: SQLite
